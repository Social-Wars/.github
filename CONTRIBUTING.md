Contribuir a Social Wars Reawakened

¡Gracias por tu interés en contribuir a Social Wars Reawakened! ❤️

Social Wars Reawakened es un proyecto de preservación y recreación de Social Wars, cuyo objetivo es recuperar y reconstruir la experiencia del juego original, manteniendo su comportamiento, sistemas y contenido lo más fieles posible al original, mientras se proporciona una base moderna para su mantenimiento, modificación y desarrollo por parte de la comunidad.

Este proyecto requiere conocimientos técnicos específicos debido a la naturaleza del juego original y de las tecnologías utilizadas durante su desarrollo.

---

📋 Requisitos para contribuir

Para contribuir directamente al código fuente del proyecto, se recomienda contar con al menos 2 años de experiencia práctica en una o varias de las tecnologías relacionadas con el área en la que deseas colaborar.

No es necesario dominar todas las tecnologías mencionadas. La experiencia requerida dependerá del área específica en la que quieras contribuir.

🐍 Python

Para trabajar en herramientas, servidores, sistemas de datos, utilidades o componentes relacionados con la infraestructura del proyecto:

- Experiencia práctica de 2+ años con Python.
- Conocimiento sólido de:
  - Programación orientada a objetos.
  - Estructuras de datos.
  - Manejo de excepciones.
  - Módulos y paquetes.
  - JSON, XML y otros formatos de datos.
  - Networking y comunicación cliente-servidor.
  - APIs y servicios web.
  - Serialización y deserialización de datos.
  - Debugging y profiling.
- Capacidad para trabajar con código existente y mantener su compatibilidad.
- Conocimiento de Git y GitHub.

---

🧪 Calidad del código

Las contribuciones deben procurar mantener un código:

- Claro.
- Legible.
- Mantenible.
- Modular.
- Reutilizable.
- Documentado cuando sea necesario.
- Compatible con la arquitectura existente.
- Libre de cambios innecesarios.

Evita introducir dependencias externas cuando no sean realmente necesarias.

Antes de enviar una Pull Request, asegúrate de que tu código:

1. Compila correctamente.
2. No rompe sistemas existentes.
3. Ha sido probado.
4. No introduce errores conocidos.
5. Respeta la estructura del proyecto.
6. Incluye documentación cuando corresponda.

---

📝 Pull Requests

Antes de crear una Pull Request:

1. Crea una rama específica para tu cambio.
2. Realiza únicamente los cambios relacionados con el objetivo de la rama.
3. Prueba tus modificaciones.
4. Revisa tu propio código.
5. Escribe commits descriptivos.
6. Explica claramente qué has cambiado.
7. Indica cómo has probado los cambios.
8. Menciona cualquier limitación o problema conocido.

Ejemplo:

feature/reconstruct-battle-system

o:

fix/player-session-handling

---

🐛 Reportar errores

Si encuentras un error, utiliza el sistema de GitHub Issues correspondiente.

Un buen reporte debe incluir:

- Descripción del problema.
- Pasos para reproducirlo.
- Comportamiento esperado.
- Comportamiento actual.
- Mensajes de error.
- Logs relevantes.
- Versión del proyecto.
- Sistema operativo.
- Información adicional que pueda ayudar a reproducir el problema.

Evita crear Issues duplicados.

---

💡 Nuevas funcionalidades

Antes de desarrollar una funcionalidad grande, recomendamos abrir primero una Issue o discutir la propuesta con los mantenedores del proyecto.

Esto ayuda a evitar:

- Trabajo duplicado.
- Cambios incompatibles con la arquitectura.
- Funcionalidades que no encajan con los objetivos del proyecto.
- Pull Requests demasiado grandes.

Para cambios importantes, espera la aprobación o feedback de los mantenedores antes de comenzar una implementación extensa.

---

🔐 Seguridad

No publiques información sensible en Issues, Pull Requests o commits.

Nunca publiques:

- Contraseñas.
- Tokens.
- API keys.
- Cookies de sesión.
- Credenciales.
- Información personal.
- Datos privados.
- Claves criptográficas.

Si encuentras una vulnerabilidad de seguridad, no la publiques públicamente. Contacta primero con los mantenedores del proyecto mediante un canal privado apropiado.

🕹️ Preservación

Uno de los objetivos fundamentales de Social Wars Reawakened es preservar el conocimiento y la funcionalidad asociada al juego original.

Por ello, valoramos especialmente las contribuciones que:

- Documenten sistemas del juego.
- Recuperen información técnica perdida.
- Analicen formatos antiguos.
- Reproduzcan comportamientos del cliente original.
- Mejoren la compatibilidad.
- Faciliten futuras investigaciones.
- Eviten que el conocimiento técnico se pierda.

Siempre que sea posible, documenta cómo descubriste una determinada estructura o comportamiento, no únicamente el resultado final.

📌 Nota sobre los requisitos de experiencia
